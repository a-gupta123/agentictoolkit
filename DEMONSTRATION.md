# Demonstration

## Task
I used the MCP tool to find requirements for Movie Recommender and Crossyroad, then ran the checker on each live site in a fresh chat.

## Run 1 — Movie Recommender

The MCP tool found the filter and search requirements. The checker tested a blank form, a normal search, and a search with no matches. It returned MET for all three, reporting “Please choose at least one filter,” “Showing 8 popular titles,” and “No movies matched those filters.” I checked the screenshots and agreed.

## Run 2 — Crossyroad

The MCP tool found the movement and facing requirements. The checker tested arrow keys and WASD and initially marked everything MET. When I asked for evidence, it admitted, “The right-facing pose was never visible.” I updated the skill and reran it in a fresh chat. It captured all eight keys and marked everything MET. I checked the screenshots and agreed with the revised results.
