# Demonstration

## Task
I used the MCP tool to find requirements for Movie Recommender and Crossyroad, then ran the checker on each live site in a fresh chat.

## Movie Recommender
The checker tested blank filters, a normal search, and a search with no matches. It reported all three as MET, showing a blank-form warning, 8 movie cards, and “No movies matched those filters.” I checked the screenshots and agreed.

## Crossyroad
The checker tested arrow keys, WASD, and character facing. It initially marked everything MET but later admitted, “The right-facing pose was never visible.” I updated the skill to require clear screenshots and reran it. It captured all eight keys and reported everything as MET. I checked the screenshots and agreed with the revised results.
